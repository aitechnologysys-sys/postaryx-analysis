# Put your HTML reports here

You can also add reports from the website itself: **Upload a report** in the sidebar saves the file
into this folder for you.

- One folder per category, e.g. `Product Analysis/`, `Market Research/`, `Experiments/`.
- Any `.html` file inside a folder shows up on the dashboard automatically — just refresh the page.
- Keep images and other files a report needs next to it (for example in an `assets/` folder) and
  link to them with relative paths such as `assets/chart.png`.
- Optional details (author, date, tags, description) can be added as `<meta>` tags inside the HTML
  or in a sidecar JSON file with the same name. See the project README for examples.

This README is ignored by the library — only HTML files are listed.
